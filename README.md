# Qshell

Qshell 是一款以终端为中心的现代化极速桌面服务器管理工作台。项目基于 **Tauri 2 + React 19 + Rust** 构建，将服务器资产、SSH / Telnet / RDP / BMC 连接、终端、SFTP、系统监控、Docker、服务、进程、端口、网络诊断与端口转发集中到同一个工作台中。

本 README 根据当前仓库代码整理，描述的是已经落地的能力。文末单独列出了依赖外部环境的功能和仍处于预留状态的协议，避免将接口预留误认为完整实现。

## 项目定位

- 面向开发、运维和服务器管理场景的本地桌面应用。
- 以 SSH 终端为核心，文件、监控和运维工具作为同一连接上下文中的辅助模块。
- 支持 Linux、Windows、网络设备和 BMC 等不同连接目标，并按协议展示对应能力。
- 数据默认保存在本机；密码、私钥和证书等敏感信息由 Rust 后端加密管理。
- 支持多工作台、多窗口、分屏和广播，兼顾单机维护与批量运维。

## 功能总览

### 1. 服务器与资产管理

- 管理 Linux、Windows、网络设备和 BMC 目标。
- 按设备类型选择 SSH、Telnet、RDP 或 Redfish / BMC 管理方式。
- 新建、编辑、删除、重命名和收藏服务器。
- 卡片视图与列表视图。
- 按名称、地址等信息搜索。
- 按标签、设备类型筛选（标签系统详见「标签管理」一节）。
- 多字段排序、升序和降序切换。
- 复制服务器 IP / 地址。
- 鼠标框选、`Ctrl` / `Cmd` 多选。
- 批量打开服务器，或将多台服务器放入同一个分屏工作区。
- 批量执行 SSH 命令，并汇总每台服务器的执行结果。
- 批量执行 BMC 电源操作。
- 加密导出指定或全部服务器，并通过密码解密导入。
- 测试连接并限制短时间内的重复测试请求。
- 自动识别远端操作系统信息。
- 批量检查服务器在线状态。
- 查看连接状态、最后错误和断开时间。
- 重置已保存的 SSH 主机指纹。

### 2. 协议与认证

| 目标 | 协议 | 当前认证方式 | 主要能力 |
| --- | --- | --- | --- |
| Linux / Unix 类主机 | SSH | 密码、私钥、SSH Agent、OpenSSH 用户证书 | 终端、SFTP、监控及完整运维模块 |
| 网络设备 | SSH | 密码、私钥、SSH Agent、OpenSSH 用户证书 | 交互式终端及 SSH 能力 |
| 网络设备 | Telnet | 用户名和密码 | 交互式 Telnet 终端 |
| Windows | RDP | 密码、域账号 | 调用操作系统可用的 RDP 客户端 |
| BMC | Redfish over HTTPS | 用户名和密码 | 硬件监控、电源、传感器及日志管理 |

SSH 认证和连接能力包括：

- OpenSSH、PEM、PPK 等常见私钥格式。
- 带 Passphrase 的加密私钥。
- Unix OpenSSH Agent、Windows SSH Agent / Pageant 等环境中的身份枚举与指定身份连接。
- OpenSSH 用户证书认证，即“私钥 + CA 签名的 `*-cert.pub`”，不是 HTTPS / TLS 证书。
- 主机密钥验证、已知主机指纹保存与重置。
- 连接状态机、连接代次（generation）隔离，避免旧异步事件覆盖新连接。
- 同一服务器并发连接去重。
- 自动重连和指数退避。
- 手动断开保护，避免自动重连立即重新建立连接。
- 跳板机（ProxyJump）和随服务器保存的内联代理配置。
- 连接成功后自动建立已配置的 SSH 隧道。

Telnet 支持交互式 Shell、终端尺寸、输出历史和终端编码转换。需要注意，Telnet 协议本身不加密，只应在可信网络中使用。

### 3. 工作台、标签与窗口

- 顶部多工作台标签，打开数量不设置业务上限。
- 每个独立工作台对应一个活动终端，避免隐藏终端重复执行输入。
- 标签固定合理宽度，工作台较多时保持可辨识性。
- 鼠标滚轮在标签栏上转换为横向滚动。
- 左右翻页入口和活动标签自动滚入可视区域。
- 在最后一个标签后通过“新增”入口搜索服务器，双击打开新工作台。
- 标签拖拽排序。
- 临时重命名、锁定和自定义标签颜色。
- 复制会话。
- 关闭当前、关闭其他、关闭全部。
- 分屏工作区支持 2～6 个窗格布局。
- 拖拽调整分屏比例和交换窗格位置。
- 将分屏窗格恢复为独立工作台。
- 跨窗口拖拽标签、创建新窗口和重新合并窗口。
- 使用持久挂载机制保留终端实例，减少标签切换、分屏和布局变化导致的终端重建、历史或背景丢失。

### 4. 终端

- 基于 xterm.js 6，优先使用 WebGL 渲染，支持 ANSI、256 色和 True Color。
- SSH 与 Telnet 交互式 Shell。
- PTY 尺寸自动适配窗口，并将行列变化同步到远端。
- Unicode、中文、宽字符和组合字符显示。
- 连接或重连时恢复后端当前会话中保留的输出历史。
- 用户向上滚动查看历史时保持当前视口，远端仍可持续输出。
- 显示新增输出数量并提供一键回到底部。
- 可配置每个终端的回滚行数，当前范围为 1,000～100,000 行，默认 10,000 行。
- 高频输出队列、批量合并写入和每帧渲染控制，降低大量日志对主线程的阻塞。
- 终端搜索支持上一个 / 下一个、正则表达式、大小写匹配和整词匹配。
- 复制选中内容、粘贴、清屏和复制全部输出。
- 多行或大文本粘贴安全确认。
- 铃声开关和粗体亮色显示。
- 字体、字号和关键字高亮规则。
- Web Links 自动识别和打开链接。
- 自定义终端主题以及主题导入。
- 背景图片或视频、透明度、模糊和背景尺寸设置。
- 终端主题和背景在工作台切换、分屏及重新布局后保持一致。
- OSC 7 当前目录识别。
- OSC 52 剪贴板协议。
- OSC 0 / 2 动态终端标题。
- OSC 133 命令阶段和退出状态基础解析。
- 终端录制直接写入本地文件，不依赖浏览器内存缓存后再下载。
- 可配置默认录制目录。
- 录制文件自动分卷，单卷范围 50～2,048 MB，默认 200 MB。
- 录制状态闪烁提示；停止后显示实际保存路径。

#### 终端编码

终端输入和输出均在 Rust Shell 通道中进行编码转换，并保留跨网络包拆分的多字节字符状态。可以全局选择编码，并立即应用到当前终端及后续新建、重连的会话。

当前编码集合覆盖：

- Unicode：UTF-8。
- 简体中文：GBK、GB18030、GB2312 兼容别名。
- 繁体中文：Big5。
- 日文：Shift-JIS、EUC-JP。
- 韩文：EUC-KR。
- 西欧、中欧、南欧、北欧、波罗的海和西里尔文字的 Windows / ISO 代码页。
- 阿拉伯语、希伯来语、希腊语、土耳其语、泰语和越南语代码页。
- DOS / OEM：CP437、CP720、CP737、CP775、CP850、CP852、CP855、CP857、CP858、CP860、CP861、CP862、CP864、CP865、CP866、CP869。

### 5. 命令智能与命令参考

- 命令、子命令、参数和参数值提示。
- 远程路径补全。
- Docker 镜像、容器等动态资源补全。
- 模糊匹配、Alias 映射和错误纠正。
- 根据命令热度、历史使用权重和匹配程度排序。
- 自动检测远端平台，减少不适用命令提示。
- 命令历史在本地持久化，可跨终端会话用于排序和检索。
- Linux 命令参考覆盖文件、系统、网络、监控、安全、Docker、Git、数据库、云服务、DevOps、包管理、虚拟化和语言工具链等分类。
- 常用命令收藏的新增、编辑、搜索和删除。
- 当当前输入与建议不匹配时，不拦截远端 Shell 自身的 Tab 补全行为。

### 6. 多终端广播安全

- 将输入同步发送到用户明确加入广播的工作台。
- 仅向每个工作台当前可见、活动的终端发送，避免同一服务器的隐藏会话重复执行。
- 显示广播目标数量和服务器列表。
- 多行命令在发送前明确展示目标范围。
- 识别高风险命令并要求二次确认。
- 粘贴和直接输入使用同一套广播安全路径。

### 7. 工作台文件管理

- 远端目录浏览、路径面包屑、目录树和文件列表。
- 文件排序、多选、快捷键和拖拽操作。
- 上传文件或完整文件夹。
- 下载单个或批量文件。
- 将多个远端文件打包为 `tar.gz` 或 `zip` 后下载。
- 新建文件、新建目录、删除和重命名。
- 文本及代码文件在线预览和编辑。
- PrismJS 语法高亮。
- 保存前自动备份和手动备份。
- 查看文件属性。
- 修改权限和所有者（chown）。
- 创建符号链接。
- 目录书签管理，单服务器最多保留 50 个书签。
- 删除危险路径前进行校验和确认。
- SFTP 诊断，帮助识别子系统、权限或路径问题。

### 8. 独立 SFTP 文件传输

- 本地与远端双栏文件管理。
- 左侧既可浏览本地文件，也可切换为另一台远端服务器。
- 远端服务器到远端服务器的直接传输。
- 右侧最多 10 个独立服务器标签，每个标签分别保存连接、路径、文件列表、同步浏览和目录比较状态。
- 同步浏览：以两侧当前目录为配对根，一侧切换子目录时，另一侧跟随相同相对路径。
- 目录比较：根据文件名、大小和修改时间标记仅左侧、仅右侧及内容不同的文件。
- 本地磁盘、Windows 驱动器和快捷位置浏览。
- 本地和远端搜索，支持递归搜索。
- 服务器标签筛选和隐藏文件切换。
- 文件、多个文件和文件夹拖拽传输。
- 递归统计本地文件夹大小及文件数量。
- 批量上传和下载。
- 并发数 1～10 可配置，默认 3。
- 传输速度限制，`0` 表示不限速。
- 展示总进度、当前文件、字节数、文件数、速度和耗时。
- 传输记录面板。
- 暂停、继续、取消和断点续传。
- 取消或失败后的临时文件清理。
- 文件冲突支持停止、跳过、覆盖、生成副本，并可应用到全部任务。
- 递归目录传输设置 64 层深度保护，降低符号链接循环或异常目录树造成栈溢出的风险。
- 下载前检查本地可用磁盘空间，并保留 5% 安全余量。
- 本地和远端的新建、删除、重命名及权限管理。
- 文件剪贴板复制和粘贴。
- 复制本地路径、远端路径和服务器地址。
- 远端归档下载。
- 复用并去重 SFTP / SSH 连接。

终端文件拖拽支持 ZMODEM 协议检测和同一 SSH Channel 内的数据透传；远端具备 `rz/sz` 时可使用 ZMODEM，未进入协议握手或环境不适用时可回退到 SFTP 上传。传输过程显示独立进度界面，成功后自动关闭。

### 9. 系统监控

监控数据继续通过当前 SSH 命令采集和差分计算方式获得，不要求远端额外部署 Agent。

- 系统信息：主机名、OS、内核、架构、运行时间和系统时间。
- 健康评分、告警等级、异常摘要和建议阈值。
- CPU 总使用率和历史趋势。
- CPU 用户态、系统态、I/O wait、steal 和 idle 模式占比。
- Load 1/5/15、CPU 核心数。
- 总内存、可用内存、使用率和内存压力。
- 应用占用、系统保留、Buffer、Cache、Free 的内存构成饼图。
- Swap 总量、已用量和使用率。
- 文件系统容量、可用空间和使用率，支持多挂载点。
- 多磁盘 I/O 曲线、读取、写入、吞吐和利用率。
- 多网卡切换和流量曲线；常用物理网卡优先排序。
- 网络接收 / 发送速率自适应 B、KB、MB、GB 单位。
- 网卡错包和丢包。
- TCP 已建立连接、监听、重传等统计。
- 进程列表，支持按 PID、CPU 和内存排序。
- 图表坐标、数据标注和非零起点的历史趋势渲染。
- 自动刷新与手动刷新。
- Linux 和 Windows 指标采集适配层。

### 10. Docker 与 Compose

- 容器列表、镜像列表和 Compose 项目列表。
- 启动、停止、重启和删除容器。
- 容器实时资源统计和 Inspect 信息。
- 容器日志查看、搜索、错误过滤、自动滚动、暂停和换行。
- 在容器内执行命令。
- 删除镜像和清理未使用镜像。
- Compose `up`、`down`、状态和日志。
- Compose 文件在线编辑与保存。

### 11. 服务、进程、端口与网络诊断

服务管理：

- 列出服务并按状态筛选。
- 按服务名称和描述搜索，显示启用状态及可用的内存占用信息。
- 启动、停止和重启服务。
- 查询服务状态和查看日志。
- Linux systemd 与 Windows 服务适配层。

进程管理：

- 查看 PID、CPU、内存和完整命令。
- 按 PID、名称、用户或命令搜索。
- 按关键指标排序。
- 普通终止和强制终止。

端口管理：

- 查看监听端口、协议、本地地址、PID 和进程信息。
- 按端口、地址和进程信息搜索。
- 按 PID 结束占用端口的进程。

网络诊断：

- DNS 查询。
- Ping。
- TCP 端口连通性检测。
- HTTP / HTTPS 检测。
- 历史目标快捷复用。

### 12. 端口转发、代理与隧道

- 本地端口转发（SSH `-L` 语义）。
- 远程端口转发（SSH `-R` 语义）。
- 动态 SOCKS5 转发（SSH `-D` 语义）。
- 添加、查看、停止、重启和停止全部转发。
- 显示运行和错误状态。
- 代理、跳板机和隧道配置直接归属于服务器连接，不要求用户维护独立资源入口。
- 代理连接支持密码、私钥、SSH Agent 和 OpenSSH 用户证书认证。
- 私钥和证书可从全局密钥库选择。
- 服务器连接建立后自动启动配置的隧道。

### 13. BMC / Redfish 带外管理

- 获取厂商、型号、序列号、BIOS、CPU、内存和整体健康状态。
- 查看并执行开机、关机、重启等 Redfish 电源动作，危险操作需要确认。
- 温度、风扇、电压、功率和电源模块信息。
- 传感器历史趋势。
- SEL / 事件日志查看与清空。
- 机箱定位灯控制。
- 打开 BMC Web 管理入口。
- 自动刷新。
- 多台 BMC 批量电源操作。
- 操作历史和审计记录。
- 兼容 BMC 常见的自签名 HTTPS 证书。

### 14. RDP

- Windows 服务器使用 RDP 密码或域账号配置。
- 支持分辨率预设、全屏和 16 / 24 / 32 位色深配置。
- Windows 上调用 `mstsc.exe`，并使用临时 RDP 文件及临时系统凭据。
- Linux 上优先尝试 `xfreerdp`，不可用时回退到 Remmina。
- macOS 上通过系统 `open` 打开临时 RDP 文件，需要安装可处理 RDP 文件的客户端。
- 延迟清理临时配置文件和应用创建的临时凭据。
- RDP 工作台与 SSH 终端认证逻辑相互隔离。

### 15. 密钥管理

- 全局 SSH 密钥库；服务器编辑页直接选择已有密钥或证书。
- 在服务器编辑过程中打开与密钥管理一致的全局新建 / 导入窗口。
- 新建、导入、编辑、搜索、分类和删除。
- 私钥与 OpenSSH 用户证书分开管理。
- 查看密钥关联的服务器，删除时进行关联保护。
- 应用内生成 Ed25519、RSA 3072、ECDSA P-256 和 ECDSA P-384 密钥。
- 支持 Passphrase。
- 复制公钥。
- 检测 SSH Agent 并列出可用身份。
- 私钥、证书内容存入加密数据库，不依赖原始文件路径即可连接。

### 16. 快照、日志与审计

- 一键生成系统快照。
- 快照包含系统信息、指标、服务、进程、监听端口和 Docker 状态。
- 查看原始数据、部分失败信息，复制或导出 JSON 快照。
- 读取远端日志。
- 启动 / 停止实时 Tail。
- 日志内容搜索。
- 日志路径书签支持添加别名、跳转和删除。
- 本地审计日志列表、数量统计和清理。
- 记录连接、命令和 BMC 等关键操作。

- 审计日志页面支持类型筛选、搜索、统计和清空。

- 全局键盘快捷键。
- 可配置交互音效。
- 高 DPI 和可调整窗口布局。
- 大服务器列表使用虚拟化渲染。
- 阿拉伯语 RTL 布局适配。
- 内置多语言资源（`i18n/locales`），覆盖简体中文、繁体中文、英语、日语、韩语、欧洲多语及阿拉伯语 RTL 等。
- 内置开发稳定性测试面板，用于连接、会话和高负载场景回归。

### 18. 标签管理

标签是一套**独立于服务器资产**的本地目录，存储于 SQLite 的 `tags` 表；标签可以不被任何服务器引用而单独存在（空标签也会常驻筛选下拉）。

- **下拉内联新建**：首页筛选下拉顶部提供「+ 新建标签」按钮，点击后就地输入，回车即创建；创建后下拉框保持打开、可连续新建多个标签。空名称、重复名称、超长（> 32 字符）会被拦截并给出提示。
- **与「连接目标」筛选一致的交互**：标签下拉无搜索框，顶部为「全部标签」选项，弹框固定高度、超出部分内部滚动；选中的标签行高亮并显示勾选标记，视觉与交互完全对齐设备类型筛选。
- **重命名 / 删除并级联更新**：每个标签支持 hover 重命名 / 删除；后端 `tags_*` 命令会级联更新所有引用该标签的服务器 `tags` 字段，并同步前端 store，保证筛选与显示一致。
- **筛选逻辑对称**：首页按标签过滤与按设备类型过滤完全对称（选中某标签即按 `tags.includes(tag)` 过滤服务器列表）。
- **编辑框建议来源**：服务器编辑框的标签建议为「标签目录 ∪ 服务器已有标签」，因此新建的空标签可直接在编辑服务器时选用。
- **健壮性**：旧数据 / 导入数据 `tags` 为 `undefined` 时不会让首页崩溃，而是简单地不参与匹配（与设备类型过滤的天然安全性一致）。

### 19. 账号认证与云端同步（Supabase / 自建实例）

- **多种认证方式**：支持邮箱 + 密码（应用内登录与注册）、邮箱验证码免密登录（Magic Link OTP）以及 GitHub OAuth 一键授权登录。
- **纯开源离线模式**：默认无需依赖任何云端，未配置时完全离线本地运行；所有本地核心功能与数据管理完全不受影响。
- **自建与第三方兼容服务（Bring-Your-Own-Backend）**：用户或企业团队可在「设置 -> 账号」或登录弹窗中直接填入自建 Supabase 实例或国内兼容服务（如 MemFire Cloud）的 URL 与 Anon Key，支持实时连接探测诊断与一键重置为默认。
- **URL 智能容错**：自动识别并剥离粘贴中附带的 `/rest/v1`、`/auth/v1` 或末尾斜杠，无需手动清洗格式。
- **零知识端到端加密（Zero-Knowledge E2EE）**：敏感服务器密码、SSH 私钥等凭证在同步前均在客户端本地基于主密钥加密，云端仅作为加密密文的备份与多端同步通道，保障核心资产绝不外泄。
- **开源安全合规**：代码仓库绝不硬编码任何私密密钥；严格区分客户端公开匿名密钥（Anon Key）与管理密钥（Service Role Key，绝不引入前端与客户端）。

## 数据与安全

- 服务器、SSH 密钥、证书、代理、隧道、主机指纹、标签和审计日志存储在本地 SQLite 数据库。
- 数据库敏感字段使用 AES-GCM 加密。
- 数据库主密钥保存在操作系统 Keyring，而不是写入前端配置。
- 导出文件使用用户密码通过 Argon2id 派生独立密钥，再以 AES-256-GCM 加密。
- 导入时先验证格式、版本和密文，再使用本地主密钥重新加密入库。
- 密码、Passphrase、私钥正文和证书正文不写入 localStorage。
- 云端同步采用零知识架构（Zero-Knowledge Architecture）：敏感资产在上传至 Supabase 前均在客户端本地基于主密钥加密，云端仅存储密文，云服务商与数据库管理员均无法解密。
- 开源安全合规：代码与客户端中严格只使用受 RLS（行级安全）限制的 Anon Public Key，绝不引入 Service Role Key，杜绝密钥泄露隐患。
- SSH 主机密钥校验用于识别主机身份变化。
- 远端命令参数和文件路径经过转义与输入校验，危险路径和高风险命令另行拦截。
- Tauri CSP 限制脚本、网络、媒体、字体和本地资源的加载范围。
- 应用启动时清理遗留的临时 OpenSSH 证书文件。
- RDP 临时配置和应用创建的临时凭据会延迟清理。
- 文件删除、进程终止、危险命令、广播和 BMC 电源操作具有校验或确认流程。
- 窗口销毁和应用退出时清理 Shell、Telnet、Tail、SSH 和转发资源。

## 外部依赖与当前边界

- **RDP 不是内嵌渲染器**：它调用系统或已安装的客户端。Windows 使用 mstsc；Linux 需要 FreeRDP 或 Remmina；macOS 需要可打开 RDP 文件的客户端。
- **ZMODEM 依赖远端环境**：服务器需要安装 `rz/sz`（通常由 `lrzsz` 提供）。无法进入 ZMODEM 握手时使用 SFTP 路线更稳定。
- **SFTP 依赖 SSH 服务端子系统**：服务端禁用 SFTP、权限不足、磁盘空间不足或网络中断时仍可能失败，应用会提供诊断、续传和错误信息，但不能保证所有环境永不失败。
- **BMC 自签名证书**：为兼容常见设备，Redfish 客户端允许无效 / 自签名证书；应仅连接可信管理网络中的 BMC 地址。
- **Telnet 明文传输**：协议不提供加密和可靠的服务器身份验证。
- **监控无需 Agent**：指标来自远端系统命令，因此可用字段会受操作系统版本、工具安装情况和当前账号权限影响。
- **会话恢复边界**：标签、主题和应用侧状态可以持久化，连接重建时可恢复已缓存输出；但应用进程退出后，无法原样恢复远端 PTY 中正在运行的 Shell 进程、当前目录、交互程序和全部滚动位置。需要跨重启保留远端任务时，应配合 `tmux` 或 `screen`。
- **WinRM 与 VNC**：类型定义中存在协议预留，但当前没有完整 WinRM 管理模块或通用 VNC 客户端，不应视为已支持功能。
- **终端图片协议**：当前未声明完整支持 Kitty / iTerm2 图片协议。
