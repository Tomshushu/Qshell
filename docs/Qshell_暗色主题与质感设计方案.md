## 一、 视觉疲劳根因与人机工程学调研

很多开发者会误以为*“眼睛累是因为太暗或太亮”*，但根据人机工程学与视光学研究，真正造成疲劳的核心诱因是以下三点：

```
[ 视觉疲劳三大诱因 ]
   ├── 1. 散光光晕与对焦疲劳 ──► 纯黑背景 + 灰暗文字，边缘解析力低，睫状肌被迫持续高频微调
   ├── 2. 视觉锚点剥夺 ──────► 无卡片边界、无呼吸边距，眼球在黑洞中不断漂移搜索
   └── 3. 选中态发脏暗淡 ────► 选中条反差不足，无法一眼锁定焦点，需要费力找光标
```

### 1. 视觉锚点剥夺（Lack of Visual Anchoring）
- **现象**：整个窗口一通黑到底，没有明确的边缘线和内外边距。
- **生理反应**：人类视觉系统习惯依靠“物理边界”（如边框、阴影、层级）来划定阅读区域。当失去边界锚点时，眼球在黑洞中容易产生视觉漂移，大脑必须消耗更多算力去定位内容分区。

### 2. 弱对比带来的睫状肌痉挛（Accommodation Fatigue）
- **现象**：辅助文字颜色过暗，与背景对比度不足。
- **生理反应**：为了看清暗底上的暗灰小字，人眼瞳孔被迫放大，睫状肌持续紧张收缩以增强对焦深度，注视时间稍长便出现酸胀感。

## 二、 方案设计与色彩体系（黑曜石与翡翠极光）

### 1. 结构重塑：从“全屏一通黑”走向“双栏悬浮磨砂岛屿”
- **背景画布层（Canvas）**：沉稳且低反光的深空黑曜石哑光灰（`oklch(0.20 0.015 250)`）；
- **卡片容器（Containers / Islands）**：
  - 各面板变为带有 `rounded-xl` 的独立容器；
  - 容器带有四周呼吸留白（Padding），不再硬贴屏幕边缘；
  - 容器背景采用提亮半透明微磨砂（`oklch(0.245 0.015 250)`），并带有 **1px 极细微光边缘**（`oklch(0.38 0.015 250 / 0.7)`）；
  - 用户一眼即可清晰辨识面板边界，彻底解决视觉漂移与眼疲劳。

### 2. 调色板对照表

| 界面区域 | 设计规范 | 护眼原理与优势 |
| :--- | :--- | :--- |
| **应用大底色** | **深空黑曜岩 `oklch(0.20 0.015 250)`** | 纯净中性偏暖，消除冷蓝光刺激 |
| **面板卡片** | **悬浮磨砂炭灰 `oklch(0.245 0.015 250)` + 1px 微光边** | 形成清晰物理岛屿，给予眼球视觉锚点 |
| **主文本** | **温润珍珠白 `oklch(0.92 0.005 250)`** | 对比度适中，不刺眼、无眩光散光 |
| **次要元数据** | **舒缓青石板灰 `oklch(0.70 0.015 250)`** | 清晰易读，无需眯眼费力辨识 |
| **高亮选中态** | **翡翠极光光泽 `oklch(0.55 0.15 175)` 微光** | 555nm 绿光波长对人眼视网膜最放松友好，醒目且温润 |
| **分界线槽带** | **6px 隔离带（内含微胶囊指示条）** | 左右边界一目了然，支持平滑缩放与双击恢复 |
